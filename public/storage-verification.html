核查基准日：2026-10-06。两个独立 agent 使用本站真实入库、出库、计价和导出处理逻辑，在隔离数据库试算。模拟库存没有写入在线仓库。

自己验证的方法

  1. 使用测试站独立模拟商家，先设置下方费率和免租天数，再建立产品并填写单位体积。旧入库批次保留原计价设置。
  2. 按表格顺序入库，来源选择退货、品相正品；每次确认左上方日期。出库时按表格选择实物库位。
  3. 在出入库记录核对所选实际日期，在仓储计价中选择对应月份、全部库存状态及全部计价状态。待确认费用要在未确认列表核对，正式客户账单会排除未确认费用。
  4. 验证后按操作顺序撤销模拟数据。当前月份金额会随查询日期增长，下列当前月结果只适用于 2026-10-06。

天数＝截止日期－入库日期；同日进出为 0 天，出库当天不再计一天。免租跨月连续计算。实物按所选库位扣，计价独立先进先出，不能拿地图显示天数直接乘剩余数量。
